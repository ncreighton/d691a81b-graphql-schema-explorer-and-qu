## Installation

### From VS Code Marketplace
1. Open VS Code
2. Press `Ctrl+P` (or `Cmd+P` on Mac)
3. Type `ext install digitalforge.d691a81b`
4. Press Enter

### From VSIX file
1. Download the `.vsix` file
2. In VS Code: `Extensions > ··· > Install from VSIX`
3. Select the downloaded file

## Usage

Press `Ctrl+Shift+P` and search for `GraphQL Schema Explorer and Query Builder VS Code Extension` to see all available commands.

**Keyboard shortcut:** `Ctrl+Shift+Alt+A` (or `Cmd+Shift+Alt+A` on Mac)

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `d691a81b.enabled` | `true` | Enable/disable the extension |
| `d691a81b.autoRun` | `false` | Auto-run on file open |
| `d691a81b.logLevel` | `"info"` | Log verbosity |

## Requirements

- VS Code 1.74.0 or higher
